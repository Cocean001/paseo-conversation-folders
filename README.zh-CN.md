# Paseo 对话文件夹

[English](README.md)

用文件夹、独立标签页和拖动操作整理已有的 Paseo 对话。

## 安装

守护进程和客户端需要 Paseo `>=0.16.0-beta.1 <0.18.0`。

```sh
paseo plugin install https://github.com/Cocean001/paseo-conversation-folders
```

在 **设置 → 侧边栏 → 视图** 中选择 **对话文件夹**。Paseo 按设备保存这个选择，电脑客户端、浏览器和手机需要各选一次。

## 使用

- 顶部搜索框按标题筛选对话。**进行中** 跨所有项目列出正在运行、等你授权、已完成但未读的对话，点标题可以折叠。
- 在对话菜单里点 **置顶对话**，它会固定在最上方的 **置顶** 里，最新置顶的排在前面，连接同一主机的所有设备都看得到。置顶的对话会从所在项目的列表里移走，取消置顶后回到原处；搜索和状态筛选仍能在原处找到它。
- 侧边栏偏矮时（窗口小，或 Paseo 顶部、底部的入口较多），列表会自动变紧凑：标题默认单行，**进行中** 展开后最多显示 3 条，分组标题也会变矮。
- 按最近活动排序时，**进行中** 里的对话本来就排在各自项目的最上面，所以它默认折叠成一行带数量的标题；侧边栏偏矮时也一样。你手动展开或折叠过，每台设备都会记住；手动选过的标题行数也会保留。
- 对话派出的子任务收在它下面，用一个数字表示，点开才显示。子任务只有在请求授权时才会出现在 **进行中**；有子任务等授权或出错时，这个数字会变成橙色。搜索和状态筛选会直接列出子任务。
- 标题在电脑上显示两行、手机上一行，可在 **视图与筛选 → 标题显示** 中按设备修改。标题开头如果是粘贴进来的会话编号，显示时会省略，搜索仍能按编号找到。
- 按项目分组时，每个项目先显示最近 10 条对话，其余点 **显示更多**；项目图标是和 Paseo 自带侧栏相同的彩色首字母方块。鼠标移到项目上点 **+** 即可在该项目里新建对话。按最近活动或创建时间排序时，项目内的对话分为今天、昨天、7 天内、30 天内和更早。按最近活动排序时，正在运行的对话固定排在最上面，彼此按创建先后排列，不会因为其中一个刚输出内容就来回换位置。
- 用 **新建文件夹** 按钮或服务器的 **更多 → 新建文件夹…** 新建文件夹。支持一层子文件夹，删除文件夹会保留对话。
- 拖动对话、文件夹或项目即可移动和排序。手机上长按一行后移动手指即可拖动，拖到列表边缘会自动滚动。拖动期间列表顺序保持不变，正在运行的对话更新也不会让行跳动。把项目拖到另一个项目或它展开的对话列表上，只会调整顺序，不会嵌套。文件夹旁的 **+** 可从 **当前布局** 或 **原始来源（服务器 → 工作区）** 选择对话。
- 从 **视图与筛选 → 自定义标签页 → 新建标签页…** 新建独立标签页，有标签页后才显示标签栏。各标签页分别保存文件夹，关闭后内容仍保留，可从同一菜单重新打开。
- **视图与筛选** 集中提供分组、排序、状态和显示设置。**全部折叠 → 恢复展开** 可恢复之前的展开状态。
- 项目的 **更多** 菜单可新建对话，或修改显示名称、图标、emoji、颜色、图片。桌面和网页支持最大 128 KB 的 PNG、JPEG、WebP。
- 对话右键、**更多** 按钮，或在手机上长按后不移动直接松手，可重命名、置顶、加标签、复制、归档和删除（可用时）。归档与删除需要确认，工作区操作会影响整个工作区。
- 界面语言跟随 Paseo 设置，内置英文和简体中文。

文件夹、排序、项目外观和显示设置保存在 Paseo 插件设置中，所有已连接的设备共享并实时更新；折叠状态、“显示更多”、标题行数和当前标签页只记在本设备。对话保留原服务器、工作区和文件。插件不会把这些信息上传到外部服务。

## 限制

对话重命名和永久删除通过插件所在主机上的 Paseo 命令行完成；在 Windows 上，插件直接调用 Paseo 桌面版自带的命令行，不经过 shell。远程对话请使用来源服务器的原生控件。永久删除会移除对话历史。

Paseo 自己隐藏的后台辅助 Agent 不会列出。本地目录项目的图标颜色与 Paseo 一致；带远程仓库的 Git 项目可能颜色不同，因为插件读不到远程地址。

触摸拖动已在手机尺寸的浏览器里用模拟触摸验证，尚未在手机实机上验收。手动文件夹视图里，手机上用 **上移** 调整文件夹顺序。两台真实服务器同时使用尚未完成验收；当前 API 不支持手动标为未读和打开文件管理器。
