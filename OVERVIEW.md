# Conversation folders

Conversation folders replaces the Paseo sidebar conversation list with collapsible folders. Put related conversations together, keep an unfiled section, and switch between hosts without mixing folder data.

Choose **Settings → Sidebar → Sidebar view → Conversation folders** to enable it. Select a host when more than one is connected. Use **New folder**, **+**, **⋮**, and **Organize** to manage folders and conversations.

Folder assignments are stored in Paseo plugin settings on the local Paseo installation and are keyed by host. The plugin opens existing conversations through Paseo navigation; it does not edit, delete, move, or send messages to conversations. It requires Paseo 0.16.0-beta.1 or later.
